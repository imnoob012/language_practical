6-4-18 注文にステータスを追加する

①３つの要件とそれぞれに対する実現方法
・注文の状態を確認できるように、ステータスを追加しています
  ⇨order_infoにorder_info_statusカラムを追加する。プログラムからの管理を想定しているが、注文のステータスは、enum型で管理します。既存の型である「order_status」に以下の値を挿入する
      受付済：requested
      発注済：item_ordered
      在庫確保済：item_arrived
      処理済：complete

②実際のSQL文と実行結果
  begin;
  BEGIN

  ALTER TYPE order_status ADD VALUE 'requested';
  ALTER TYPE order_status ADD VALUE 'item_ordered';
  ALTER TYPE order_status ADD VALUE 'item_arrived';
  ALTER TYPE order_status ADD VALUE 'complete';


  UPDATE order_info SET order_info_status = 'requested' WHERE order_info_id = 1;
  UPDATE order_info SET order_info_status = 'item_ordered' WHERE order_info_id = 3;
  UPDATE order_info SET order_info_status = 'item_arrived' WHERE order_info_id = 4;
  UPDATE order_info SET order_info_status = 'complete' WHERE order_info_id = 5;
